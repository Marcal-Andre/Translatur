# Translatur - Travel Agency Website

This is a frontend prototype for Translatur, a travel agency website with a black and white color scheme. The site offers various travel services including flights, accommodations, tours, tickets, transfers, cruises, travel insurance, and travel packages.

## Features

- Horizontally scrolling service blocks
- Advanced search functionality with filtering options
- Customer testimonials carousel
- Responsive design (mobile, tablet, desktop)
- Modern black and white aesthetic

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome for icons

## Structure

- `index.html`: Main entry point
- `styles/`: CSS files organized by component
- `scripts/`: JavaScript modules for each feature

## Backend Implementation Notes

This is a frontend prototype. To fully implement the site with PHP and MySQL:

1. Create a MySQL database with tables for:
   - Users/customers
   - Travel services (flights, hotels, etc.)
   - Bookings/reservations
   - Testimonials

2. Implement PHP scripts for:
   - User authentication
   - Search functionality
   - Booking system
   - Admin panel for content management
